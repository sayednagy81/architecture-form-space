# 🏛️ منصة العمارة: الشكل والفضاء والنظام
## Architecture: Form, Space & Order — Interactive Architectural Hub

منصة تعليمية تفاعلية حديثة موجهة لطلاب وأساتذة العمارة، تم تحويلها وتطويرها انطلاقاً من المادة العلمية التفاعلية للقرص المدمج لكتاب **العمارة: الشكل والفضاء والنظام (Architecture: Form, Space, and Order)** للمعماري والمؤلف العالمي **فرانسيس د.ك. شينغ (Francis D.K. Ching)** - الإصدار الثالث الصادر عن جون وايلي وأولاده (John Wiley & Sons).

---

## ✨ المميزات الرئيسية للمنصة

1. **تشغيل 25 وحدة تفاعلية كاملة (25 Interactive Modules)**:
   - تشغيل جميع ملفات العروض التفاعلية الأصلية البالغة أكثر من 340 ميجابايت (`m1_s1.swf` إلى `m7_s4.swf`) في أي متصفح حديث (Chrome, Safari, Edge, Firefox) وعلى الهواتف والأجهزة اللوحية دون الحاجة لبرنامج Flash Player القديم، بالاعتماد على محاكي **Ruffle WebAssembly**.
   - دقة عرض قياسية ثابتة (800x650) بنسبة أبعاد معمارية دقيقة وخاصية ملء الشاشة (Fullscreen).

2. **طابع المخطط المعماري الهندسي (Blueprint Drafting Aesthetic)**:
   - تصميم بصري هندسي مستوحى من كراسات ومسودات فرانسيس شينغ اليدوية مع إمكانية التبديل الفوري بين 3 أنماط:
     - **Blueprint Blue**: المخطط الأزرق المعماري الكلاسيكي مع خطوط شبكية نيون.
     - **Vellum Paper**: الورق الكريمي الشفاف المعماري بلمسة تحبير حقيقية.
     - **Dark Studio**: استوديو التصميم المعماري الليلي عالي التباين.

3. **المختبر المعماري ثلاثي الأبعاد (Interactive 3D WebGL Studio)**:
   - بيئة محاكاة 3D تفاعلية مبنية بتقنية Three.js تتيح للطلاب تدوير ومعاينة المفاهيم الهندسية الفراغية:
     - النقطة وتأثير نقطتين (Point & Implied Axis)
     - الخط ورواق الأعمدة المعمارية (Line & Colonnade)
     - المستويات وتحديد الفضاء بالسقف (Base, Wall & Overhead Canopy)
     - الحجم والتشكيل الطرحي (Volume & Subtractive Void)
     - الفضاءات المتداخلة (Interlocking Spaces)
     - التنظيم المركزي والقبة (Centralized Organization)
     - المرجع الحاكم للكتل المتباينة (Datum Spine)
   - دعم أنماط العرض: الإطار السلكي (Blueprint Wireframe)، الكتلة المصمتة (Solid Mass)، والشفافية الداخلية (X-Ray).

4. **معجم المصطلحات المعمارية ثنائي اللغة (Architectural Glossary)**:
   - قاموس معماري تفاعلي يضم المصطلحات المحورية في نظرية العمارة مع تعريف أكاديمي باللغتين العربية والإنجليزية، وفلترة سريعة حسب الفصول.

5. **بنك أسئلة واختبارات تقييم ذاتي (Architectural Self-Assessment Quizzes)**:
   - اختبارات تفاعلية قصيرة لكل فصل من فصول الكتاب السبعة، مع تصحيح فوري وشرح معماري تحليلي للإجابة الصحيحة.

6. **دعم كامل للغتين (العربية / الإنجليزية)**:
   - تبديل سلس بين العربية والإنجليزية مع التكيف التلقائي لاتجاه الواجهة (RTL / LTR).

## 🚀 كيفية التشغيل محلياً على جهازك (Local Run)

المنصة مصممة لتعمل بدون أي تثبيتات معقدة. نظرًا لأن ملفات WebAssembly و Flash تتطلب تشغيل خادم محلي لتجاوز قيود أمان المتصفح (CORS):

### الطريقة الأولى: باستخدام Python (الأسهل)
افتح موجه الأوامر (Terminal / PowerShell) في مجلد المشروع واكتب:
```bash
python run_local.py
```
سيقوم السكربت ببدء خادم محلي وفتح المتصفح تلقائياً على الرابط:
`http://localhost:8080/index.html`

### الطريقة الثانية: باستخدام أي خادم محلي
```bash
# باستخدام Python المدمج
python -m http.server 8080

# أو باستخدام Node.js
npx serve .
```

## 🌐 خطوات الرفع والنشر المباشر على GitHub Pages

المشروع مهيأ تماماً ليعمل كـ **موقع شخصي مجاني مستضاف على GitHub Pages**:

1. أنشئ مستودعاً جديداً (New Repository) على حسابك في GitHub (مثلاً باسم: `ching-architecture-hub`).
2. افتح موجه الأوامر داخل هذا المجلد ونفذ الأوامر التالية:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Ching Architectural Hub"
   git branch -M main
   git remote add origin https://github.com/<YOUR_USERNAME>/<REPO_NAME>.git
   git push -u origin main
   ```
3. في صفحة المستودع على GitHub:
   - اذهب إلى **Settings** ⚙️ > ثم من القائمة الجانبية اختر **Pages**.
   - تحت قسم **Build and deployment**:
     - اختر Source: `Deploy from a branch`.
     - اختر Branch: `main` و المجلد `/ (root)`.
   - اضغط **Save**.
4. خلال دقيقة واحدة، سيمنحك GitHub رابط موقعك الحي مثل:
   `https://<YOUR_USERNAME>.github.io/<REPO_NAME>/`
   وسيصبح الموقع متاحاً لجميع الطلاب والباحثين حول العالم!
